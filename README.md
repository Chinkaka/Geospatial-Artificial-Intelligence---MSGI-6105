# Geospatial Artificial Intelligence (MSGI-6105)
# Module description
This module examines how artificial intelligence can support the analysis, interpretation, and prediction of geographic phenomena. Students develop reproducible workflows for acquiring geospatial data, preparing training datasets, building machine-learning and deep-learning models, and communicating spatial predictions.

The module emphasizes spatial autocorrelation, scale, uneven sampling, spatial and temporal leakage, and transferability between locations. Applications include land-cover mapping, agriculture, flood exposure, urban development, environmental monitoring, and mineral-related landscape change. Practical work uses Python notebooks in Google Colab and critically examines performance, uncertainty, ethics, and suitability for decision-making

# Prerequisites
Introductory GIS, remote sensing, statistics, and Python. Students should understand coordinate reference systems, raster and vector data, sampling, descriptive statistics, and basic programming constructs. A pre-course diagnostic and bridging exercise covers functions, arrays, tables, plotting, and notebook execution.

# Module aim
To equip students with the conceptual understanding, programming skills, and critical judgement needed to design, implement, evaluate, and communicate GeoAI solutions to geographic research and planning problems.
